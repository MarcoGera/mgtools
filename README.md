# MGtools

**MGtools** — кроссплатформенный органайзер для **Android** и **Windows ПК**: закладки, заметки, напоминания, папки/группы и изображения с синхронизацией через обычный JSON-файл.

Никакого собственного сервера и аккаунта не требуется: обмен данными идёт через файл `mgtools_sync.json`, который можно хранить в Google Drive, OneDrive, Яндекс.Диске или просто перекидывать через Quick Share.

**Репозиторий:** https://github.com/MarcoGera/mgtools  
**Готовые сборки (Releases):** https://github.com/MarcoGera/mgtools/releases

## Возможности

### Закладки
- Сохранение ссылок с названием, описанием и тегами.
- Автоматическое открытие ссылки через `url_launcher` (добавляет `https://`, если протокол не указан).
- Поиск по названию, описанию, URL, тегам и названию папки.
- Фильтр по тегам и по закреплённым записям.
- Вложения-изображения.

### Заметки
- Многострочный текст.
- Чек-лист внутри записи.
- **Вынесенный вниз чекбокс «Выполнено»** с сильным визуальным выделением:
  - зелёная рамка и фон карточки;
  - надпись `✓ ВЫПОЛНЕНО`;
  - зачёркнутый заголовок;
  - кнопка «Выполнено (нажмите, чтобы снять)».
- Приоритет и цвет записи.
- Закрепление записи.
- Сохранение **каждой заметки в отдельный JSON-файл** и загрузка из него.

### Напоминания
- Дата и время напоминания.
- Уведомления на Android (высокий приоритет, публичный канал, вибрация, звук).
- Точные будильники (`exactAllowWhileIdle`) где это разрешено системой.
- Локальные уведомления на Windows/Linux через `flutter_local_notifications`.
- Дополнительный «foreground watcher»: если приложение открыто, уведомление продублируется в интерфейсе и системным уведомлением.
- Кнопка «Выполнено» прямо в окне напоминания.

### Папки / группы
- Создание, переименование и удаление папок (например, «Работа»).
- Цвет папки из палитры.
- Закрепление папки — закреплённые поднимаются вверх списка.
- Перемещение записи в папку через выпадающий список в редакторе.
- Фильтр «Все / Без папки / конкретная папка».
- Папки участвуют в синхронизации наравне с записями.

### Изображения
- Прикрепление нескольких изображений к закладке или заметке.
- Изображения хранятся прямо в данных как `data:image/...;base64,...`, поэтому переезжают вместе с JSON-файлом.
- Предпросмотр миниатюр в карточке и в редакторе, удаление вложений.

### Синхронизация
- Экспорт и импорт одного файла `mgtools_sync.json`.
- **Умное слияние** по `id` + `updatedAt`: более новая версия побеждает, дубликаты не создаются.
- Поддержка «могильных камней» удаления: удалённая запись не воскресает после импорта старого файла.
- Привязка к файлу: после «Сохранить как» в папке облачного диска изменения записываются в него автоматически.
- Перенос одной записи через отдельный файл.

## Установка готовых сборок

### Android (S25 Plus)
1. Скопируйте `MGtools-v1.1.0.apk` на телефон.
2. Откройте файл в проводнике телефона.
3. Разрешите установку из неизвестных источников для используемого файлового менеджера.
4. Нажмите **Установить**.

### Windows
1. Распакуйте `MGtools-Windows.zip` в любую папку.
2. Запустите `mgtools.exe` из распакованной папки.

> Важно: `mgtools.exe` не работает один без соседних DLL и папки `data`. Запускайте именно из полной папки.
>
> При первом запуске SmartScreen может предупредить о неподписанном приложении: **Подробнее → Выполнить в любом случае**.

## Сборка из исходников

### Требования
- Flutter SDK **3.50.0** (Dart 3.14.0).
- Android SDK с платформой **android-36** и build-tools 36.0.0.
- JDK из Android Studio (используется автоматически).
- Для Windows: Visual Studio 2022 с workload **Desktop development with C++** и Windows 10 SDK.

### Команды

```powershell
flutter pub get
flutter analyze
flutter test

# APK для телефона
flutter build apk --release
# → build\app\outputs\flutter-apk\app-release.apk

# EXE для Windows
flutter build windows --release
# → build\windows\x64\runner\Release\mgtools.exe
```

### ⚠️ Кириллический путь к проекту

Android Gradle Plugin и Dart AOT-компилятор корректно работают только с ASCII-путями. Если проект лежит, например, в `C:\Users\<Имя>\Documents\Проект по умолчанию`, сборка APK упадёт с ошибкой «non-ASCII characters» или «Unable to read file app.dill».

Решение — собрать из копии с латинским именем:

```powershell
robocopy "C:\Users\<Имя>\Documents\Проект по умолчанию" "C:\Users\<Имя>\mgtools_build" /E /XD build .dart_tool .idea .gradle
cd C:\Users\<Имя>\mgtools_build
flutter build apk --release
```

Готовый APK можно скопировать обратно в основную папку проекта.

### Особенности конфигурации Android

В `android/gradle.properties` включено:

```properties
android.overridePathCheck=true
```

В `android/app/build.gradle.kts` включены:

```kotlin
compileSdk = 36
isCoreLibraryDesugaringEnabled = true
```

и добавлена зависимость:

```kotlin
coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.1.4")
```

Это необходимо для `flutter_local_notifications` и совместимости плагинов с AGP 9.3.1.

## Как работает синхронизация

### Коротко

**Полностью автоматической двусторонней синхронизации нет.** Есть:

1. автоматическая запись изменений в **привязанный файл**;
2. ручное слияние при получении изменений с другого устройства;
3. сам Google Drive / OneDrive синхронизирует сам файл в облако.

### Привязка файла

На **Windows** кнопка **Синхр. → Экспорт JSON** открывает системное окно «Сохранить как». Если сохранить `mgtools_sync.json` прямо в папку Google Drive Desktop, приложение запоминает этот путь.

После этого **при каждом изменении** (новая запись, редактирование, чекбокс, папка) файл автоматически перезаписывается. Google Drive видит изменение файла и загружает его в облако.

На **Android** экспорт идёт через меню «Поделиться», поэтому итоговый путь в Drive не запоминается. Для телефона экспорт/импорт — ручная операция.

### Что нужно делать вручную

| Ситуация | Действие |
|---|---|
| Изменили данные на ПК | Ничего: файл в папке Drive обновится сам |
| Изменили данные на телефоне | **Синхр. → Экспорт JSON** → Поделиться → Google Drive → сохранить с заменой |
| Подтянуть изменения с другого устройства | **Синхр. → Синхронизировать с привязанным файлом** или **Импорт и слияние** |
| Перенести одну заметку | Кнопка «Сохранить в файл» на карточке / «Загрузить одну заметку из файла» |

### Умное слияние

- Сравнение по `id` и `updatedAt`.
- Побеждает более новая версия записи или папки.
- Дубликаты не создаются.
- Удалённые записи помечаются `isDeleted: true` и не «воскресают».
- Результат слияния сразу записывается обратно в файл.

Можно экспортировать/импортировать файл любое количество раз — данные не задвоятся.

### Рекомендованный сценарий

1. **На ПК один раз:** Синхр. → Экспорт JSON → сохранить в папку Google Drive.
2. **На ПК дальше:** просто работайте — файл обновляется сам.
3. **На телефоне после изменений:** Синхр. → Экспорт JSON → Google Drive (с заменой).
4. **Чтобы подтянуть на ПК:** дождитесь скачивания файла Drive → Синхр. → Синхронизировать с привязанным файлом.

## Формат данных

### Общий файл синхронизации

```json
{
  "app": "MGtools",
  "schemaVersion": 2,
  "exportedAt": "2026-11-25T12:00:00.000Z",
  "device": "windows",
  "items": [ /* массив записей */ ],
  "folders": [ /* массив папок */ ]
}
```

### Запись

```json
{
  "id": "uuid",
  "type": "note",
  "title": "Заголовок",
  "content": "Текст заметки",
  "url": null,
  "tags": ["работа", "важное"],
  "reminderAt": "2026-11-25T15:00:00.000Z",
  "isCompleted": false,
  "isPinned": false,
  "priority": "medium",
  "colorHex": "#3B82F6",
  "checklist": [],
  "images": ["data:image/png;base64,..."],
  "folderId": "uuid-папки",
  "createdAt": "2026-11-25T10:00:00.000Z",
  "updatedAt": "2026-11-25T11:00:00.000Z",
  "isDeleted": false
}
```

Возможные значения `type`: `bookmark`, `note`, `reminder`.  
Возможные значения `priority`: `low`, `medium`, `high`.

### Папка

```json
{
  "id": "uuid",
  "name": "Работа",
  "colorHex": "#3B82F6",
  "isPinned": true,
  "createdAt": "...",
  "updatedAt": "...",
  "isDeleted": false
}
```

### Отдельный файл заметки

```json
{
  "app": "MGtools",
  "schemaVersion": 2,
  "singleItem": true,
  "item": { /* запись */ },
  "folder": { /* папка, если была назначена */ }
}
```

## Уведомления

- Канал Android: `mgtools_reminders_channel`, название «Напоминания MGtools».
- `Importance.max`, `Priority.high`, вибрация и звук включены.
- `NotificationVisibility.public` — уведомление отображается на экране блокировки.
- Запрашиваются разрешения на уведомления и точные будильники.
- Windows/Linux: локальные уведомления через `flutter_local_notifications`.
- Веб-версия: Notification API браузера (требует разрешения).

## Скрипты иконок

### Android

```powershell
powershell -ExecutionPolicy Bypass -File tools\set_app_icon.ps1 `
  -SourceImage "C:\path\to\icon.png" `
  -ProjectRoot "%CD%"
```

Скрипт создаёт:
- `ic_launcher.png` для mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi;
- `ic_launcher_round.png`;
- `ic_launcher_foreground.png`;
- `values/ic_launcher_background.xml`;
- `mipmap-anydpi-v26/ic_launcher.xml`;
- добавляет `android:roundIcon` в манифест.

Исходное изображение центрируется и обрезается до квадрата; фон адаптивной иконки берётся как средний цвет изображения.

### Windows

```powershell
powershell -ExecutionPolicy Bypass -File tools\set_windows_icon.ps1 -ProjectRoot "%CD%"
```

Скрипт собирает multi-size `app_icon.ico` (16–256 px) из `mipmap-xxxhdpi/ic_launcher.png`.

> После замены иконки Windows выполните чистую сборку: `flutter clean` → `flutter build windows --release`.

## Известные ограничения

- Приложение **не отслеживает автоматически внешние изменения файла** — нужно нажать «Синхронизировать с привязанным файлом».
- На Android «Экспорт JSON» не создаёт постоянную привязку к облачному пути.
- Изображения хранятся в base64 внутри JSON — файл синхронизации растёт при большом количестве фото.
- Release-APK подписан отладочным ключом (для личного пользования этого достаточно; для Google Play нужен свой signing key).
- Net-to-cloud «как в Google Docs» нет: это файловая синхронизация, а не реальное время.
